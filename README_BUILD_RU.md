# Hulk Native PC — реально сделанный код, а не готовый ремастер

**Статус: 5 ноября 2026, v0.4 NativeBridge.** Это *исходный проект* для сборки на Windows. Проверен платформенно-независимый C++ модуль ввода через Clang + CTest. Полноценная игра и Vulkan здесь не запускались. Не заменяйте исходный установленный EXE этим архивом.

## Что нового относительно v0.1

1. Создан `BUILD_WINDOWS.cmd` + `BUILD_WINDOWS.ps1`: установка SDK ReXGlue из ветки `recomp`, генерация игрового кода из твоего `default.xex`, сборка Windows x64 и помещение EXE/DLL в `out/HULK_NATIVE_PC_TEST/`.
2. Пользователю не требуется снова распаковывать многогигабайтные `.ARC`: для codegen копируется только `default.xex` из установленной папки, а новая сборка использует старую папку данных через `--game_data_root`.
3. Исправлена проблема конкурирующих виртуальных геймпадов: в запускающем скрипте отключается встроенный `mnk_mode` ReXGlue, при этом включается мост ввода Hulk (`hulk_native_mnk`). Есть необязательное `--hulk_native_mnk_force=true` для экспериментов с уже подключённым контроллером; **по умолчанию он выключен, чтобы не подавлять физический геймпад**.
4. Улучшена защита оконного перехвата `game_window.cpp`: проверка успешности подклассификации и повторное обнаружение окна после его уничтожения.
5. Проверки раскладки кнопок, аналоговых осей и big-endian `XINPUT_STATE` переведены с `assert()` на проверку, активную и в Release; тесты выполняются перед полной сборкой.
6. Подключение NativeXRenderer через CMake поддерживает отдельное полное Git-дерево с подмодулями, не переписывая присланные пользователем исходники.

## Как получить первую сборку с нашим управлением

**Нужны Windows 11, Visual Studio 2022 / Build Tools (Desktop development with C++, LLVM Clang), Git, Python 3, CMake, Ninja и интернет.** Это не требует написания кода руками. Свободное место — с запасом, поскольку генерация и компиляция большого игрового кода занимают много места.

1. Распакуй весь ZIP в **отдельную** папку, например `E:\HulkNativeSource`. Не клади его поверх `E:\Games\IncredibleHulk`.
2. Запусти `BUILD_WINDOWS.cmd`. Если игра установлена по твоему ранее показанному пути, скрипт сам найдёт `E:\Games\IncredibleHulk\games\incredible_hulk\game\default.xex`. Иначе укажи папку при запросе или через `BUILD_WINDOWS.cmd -GameRoot "ПОЛНЫЙ_ПУТЬ"`.
3. Сборщик загружает зависимости (SDK) **из GitHub на твоём ПК**, генерирует код и проверяет ввод, потом пытается собрать всю игру.
4. Если сборка прошла, открой `out\HULK_NATIVE_PC_TEST\RUN_HULK_NATIVE.cmd`. Файлы сохранений лежат отдельно в `%LOCALAPPDATA%\HulkNativePC\Saves`.
5. Если не прошла, пришли сюда **`HULK_BUILD_LOG.txt`** из папки проекта, а не повторяй загрузку всех архивов.

Запуск нового EXE отключает штатное `--mnk_mode` ReXGlue и включает собственный ввод. WASD — ходьба; мышь — прямое обновление углов камеры только при наличии достоверного профиля, иначе эмуляция правого стика; Space — A, левая кнопка мыши — X, правая — B, Enter — Start, Tab — Back. F8 переключает захват ввода. **Прямой путь мыши написан, но отключён без проверенных адресов камеры**; кнопки и движение пока остаются мостом к консольному управлению.

### NativeXRenderer

Для сборки интегрированного Vulkan-моста можно запустить `BUILD_WINDOWS.cmd -NativeXLink`, это скачает полный NativeXRenderer вместе с DiligentCore и соберёт библиотеку при наличии совместимых зависимостей. **Важно:** даже успешная сборка этого режима *сама по себе ещё не заменяет Xenos на Vulkan*. Графический профиль XDK 2.0.6534 (области `DeviceLayout`, `ObjectLayout`, карта точек входа) нуждается в дальнейшей проверке по трассировкам; включение нативного вывода сейчас могло бы сломать игру.

## Проверено и не проверено

| Проверка | Статус |
|---|---|
| CMake проекта автономных тестов | Успешно на Linux |
| Компиляция `native_input_map.cpp` Clang C++23 | Успешно |
| CTest, реальные проверки в Release | Успешно |
| Автоматическая сборка Windows PowerShell | Код написан, **на Windows не запускался** |
| Изменённый EXE в Hulk | **Не собирался/не проверялся здесь** |
| NativeXRenderer: интеграция Vulkan | **Мост и хуки реализованы; фактический вывод ещё заблокирован отсутствующим достоверным XDK-профилем** |
| Нативная камера | **Код есть и протестирован на искусственной памяти; в игре отключён, пока не найдены поля камеры** |
| Настоящий 4K и меню графики | **Не реализованы** |

**Юридически:** исходники Hulk Recompiled и NativeXRenderer распространяются с их собственными лицензиями (прикреплены). Данные оригинальной игры в ZIP не входят: используются файлы из принадлежащей пользователю копии.

## Разработчику

Файл `Hulk_NativePC_v0.2_source_changes.patch` применяется к оригинальному репозиторию Hulk (ZIP от 2 ноября) с параметром `git apply --ignore-space-change` — исходные `.cpp` были сохранены с CRLF. Для обычной сборки patch применять не нужно: в архиве уже полное изменённое дерево.


## Диагностические возможности v0.3 (5 ноября 2026)

Изолированные наблюдения XDK и ввода, НЕ готовый нативный Vulkan: 
`BUILD_WINDOWS.cmd -Pm4Probe -InputProbe` запускает сборку с безопасными read-only хуками графических PM4 кандидатов и трёх точек чтения XInput. По умолчанию обе опции выключены. Подробные сведения в `docs/HULK_CONTINUATION_2026-11-05.md`. Игровую работоспособность этих хуков нужно проверить на Windows.


## Состояние NativeXRenderer v0.4

Теперь `-NativeXLink` не только линкует библиотеку: добавляет конфиг-парсер,
генерирует `REX_HOOK_RAW` для гостевых функций, и вызывает `Initialize()` после
валидации профиля. **Не является законченным Vulkan-портом**, пока не восстановлены
реальные XDK 6534 offsets и не указаны реальные `Present`, `Resolve`, `SetTexture` и
остальные API. Подмена адресов случайными значениями недопустима.

Читайте `docs/HULK_NATIVE_GPU.md`. `-Pm4Probe` и `-NativeXLink` одновременно
не использовать (двойные определения перехватчиков).
